## 遇到的问题与解决过程

**问题 1：脚本直接运行时 `from .bearing import ...` 相对导入报错。**

```
ImportError: attempted relative import with no known parent package
```

排查：直接 `python3 src/week1-bearing-ml/01_explore.py` 运行时没有包上下文，相对导入失效。
解决：各入口脚本顶部加 `sys.path.insert(0, src目录)` 引导，`common/` 内部统一改成
`from common.bearing import ...` 绝对导入。这样既支持单脚本运行，也支持从项目根统一调用。

**问题 2：XJTU-SY 轴承几何参数不确定，包络谱特征频率没法直接标定。**

排查：包络谱特征（BPFO 等）依赖滚动体数 Z、节径 D、球径 d、接触角 α，网络资料说法不一，
不能随便编一个数。解决：先从本地《XJTU-SY滚动轴承加速寿命试验数据集解读》（数据集
"Important References" 文件夹自带 PDF）表 1 核实型号为 **LDK UER204**：Z=8、球径 7.92 mm、
中径 34.55 mm、接触角 0°，写入 `common/bearing.py` 的 `BearingGeometry` 默认值和
`config/xjtu_bearing_geometry.json`；参数保留 `--geometry-json` 覆盖入口，换其他型号轴承时可直接指定。
