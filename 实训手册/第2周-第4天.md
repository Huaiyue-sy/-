## 做了什么

1. **数据管道（`common/cv.py`）**：
   - `stratified_split()` 按类别分层划分 train/val/test = 8:1:1（seed=42 可复现）；
   - 训练集增强：Resize(224) + 水平翻转 + 旋转 ±10°；验证/测试只 Resize+Normalize；
   - 灰度图转 3 通道再按 ImageNet mean/std 归一化（`Grayscale→RGB` + Normalize）。
2. **模型**：`torchvision` ResNet18，加载 ImageNet 预训练权重，替换 `fc` 为 6 类输出；
   预训练权重下载失败时自动降级随机初始化（脚本里有 try/except 与提示）。
3. **训练**：Adam lr=1e-3，batch=32，epochs=15；以验证集准确率最高的 epoch 权重为准
   （`train_image_classifier` 内部保存 best state）。
4. **评估与产出（`results/week2_3/`）**：
   - `history_resnet18_CE_lr0.001.csv` 训练曲线数据 + `curve_...png`；
   - `cm_resnet18_...png` 六类混淆矩阵；`resnet18_results.csv` 指标行；
   - 模型 `models/resnet18_neu.pth`（含类别表、img_size、测试准确率）。
5. **结果（本次实测，ImageNet 预训练微调）**：测试准确率 = 0.9944；macroF1 = 0.9944；
   180 张测试图仅错 1 张：1 张 scratches（划痕）被误判为 patches（斑块），
   两者都是低对比度细长纹理，局部形态接近。从零训练对照仅 0.8944，迁移学习提升约 10 pp。

## 遇到的问题与解决过程

**问题 1：预训练权重下载失败（Python 内 SSL 证书校验不通过）。**

```
URLError: <urlopen error [SSL: CERTIFICATE_VERIFY_FAILED] certificate verify failed>
```

排查：`download.pytorch.org` 在机房网络下不稳定，且本机 Python 的 certifi 证书链不全。
解决：先用 curl 把 `resnet18-f37072fd.pth`、`efficientnet_b0` 权重直接下到
`~/.cache/torch/hub/checkpoints/`，torchvision 命中本地缓存后不再联网，预训练微调成功。
第一次没拿到权重时用随机初始化先跑通了流程，结果另存为 `*_scratch.csv` 作对照：
ResNet18 从零 0.8944 → 预训练 0.9944（+10 pp）；EfficientNet-B0 从零 0.9944、
预训练 0.9889（180 张测试图差 1 张，属随机波动）。每组实验的初始化方式都写进了结果 CSV 的
`pretrained` 字段，报告中如实标注。

**问题 2：NEU-DET 是灰度图，直接送进 ResNet 报维度错。**

```
RuntimeError: Given groups=1, weight of size [64, 3, 7, 7], expected input to have 3 channels
```

原因：第一层卷积按 3 通道预训练。
解决：`ImageDataset` 里 `convert("L").convert("RGB")` 复制成 3 通道（不是伪彩色，仅复制通道），
语义不变，与 ImageNet 预训练对齐。
