# 工艺文件：氧化铁皮压入（rolled-in scale）【模拟文件，供智能体 RAG 演示】

## 缺陷定义
带钢表面被压入的氧化铁皮，呈暗色片状/条带状分布，多出现于上表面，深度约 10–50 μm。

## 常见工艺原因
1. **除鳞系统压力不足**：高压除鳞水压低于 15 MPa 时，一次氧化铁皮去除率明显下降，压入风险随轧制温度升高而增大。
2. **板坯加热温度过高**：加热炉均热段温度超过 1280 ℃，氧化铁皮增厚且与基体结合力变强。
3. **粗轧道次除鳞箱喷嘴堵塞**：喷嘴堵塞率超过 20% 时，局部除鳞盲区扩大。
4. **轧辊辊面粗糙度异常**：辊面粗糙 Ra > 8 μm 时易粘附铁皮并反向压印。

## 关联工序
加热炉 → 除鳞箱 → 粗轧（R1/R2）→ 精轧。

## 处置建议
- 检查除鳞泵站压力与各喷嘴堵塞情况，必要时停机更换喷嘴；
- 核对加热炉各段温度设定，避免均热段超温；
- 在精轧入口加装残皮检测报警，连续出现时降低轧制节奏。

## 预防措施
- 每班点检除鳞喷嘴，建立堵塞台账；
- 板坯在炉时间控制在工艺卡上限以内；
- 定期检测轧辊表面粗糙度并及时磨辊。
