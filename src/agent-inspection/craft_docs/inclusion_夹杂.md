# 工艺文件：夹杂（inclusion）【模拟文件，供智能体 RAG 演示】

## 缺陷定义
钢板表面肉眼可见的点状/条状非金属夹杂物暴露，颜色与基体差异明显，多为耐火材料、保护渣或脱氧产物。

## 常见工艺原因
1. **中间包/结晶器保护渣卷入**：拉速波动超过 ±0.15 m/min 时液面波动，保护渣卷入几率增大。
2. **钢水洁净度不足**：夹杂物上浮时间不够，精炼软吹时间低于 8 分钟时效果差。
3. **耐火材料侵蚀脱落**：中间包挡渣墙、水口侵蚀率高时，颗粒状夹杂增多。
4. **脱氧产物（Al₂O₃）聚集**：铝脱氧后钙处理不充分，夹杂物呈簇状。

## 关联工序
炼钢（转炉→精炼→连铸）→ 热轧。

## 处置建议
- 夹杂连续报警时优先复核连铸拉速与液面控制曲线；
- 取样做夹杂评级（GB/T 10561），判断来源是内生还是外来；
- 联系炼钢工序核查精炼软吹与钙处理记录。

## 预防措施
- 稳定拉速、投用液面自动控制；
- 按寿命更换水口与挡渣墙；
- 精炼软吹时间按工艺卡下限执行并记录。
