# 工艺文件：龟裂（crazing）【模拟文件，供智能体 RAG 演示】

## 缺陷定义
钢板表面网状/龟甲状微裂纹，多沿晶界分布，常见于含铜、锡等残余元素较高的钢种表面。

## 常见工艺原因
1. **加热温度与残余元素耦合**：Cu、Sn 残余元素偏高且加热温度超过 1250 ℃ 时，表面富集相熔化沿晶界开裂。
2. **温度骤变**：除鳞水与高温板坯表面温差过大，热应力诱发微裂纹。
3. **合金成分偏析**：连铸偏析段在热轧应力下优先开裂。
4. **轧辊温度低、压下量过大**：咬入冲击使表面微裂纹扩展。

## 关联工序
加热炉 → 粗轧 → 精轧。

## 处置建议
- 出现龟裂立即取样做金相+能谱，确认是否为 Cu/Sn 富集；
- 复核该批次钢种成分单与加热炉温度记录；
- 降温轧制试验：加热温度下调 30–50 ℃ 验证敏感性。

## 预防措施
- 残余元素 Cu+Sn 控制在采购标准内并逐炉记录；
- 对敏感钢种设定专用加热曲线；
- 控制除鳞水温差与喷射角。
