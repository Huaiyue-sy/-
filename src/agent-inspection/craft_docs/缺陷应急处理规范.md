# 缺陷应急处理规范【模拟文件，供智能体 RAG 演示】

## 响应分级
- **一级（单次出现）**：正常记录，纳入质量台账，不干预生产。
- **二级（同类缺陷 3 次连续出现，同一机台）**：触发预警，通知班组长复核该机台工艺参数。
- **三级（同类缺陷 5 次以上连续出现，或一台班内同类缺陷 ≥ 10 次）**：停机排查，质量工程师到场，按对应工艺文件逐项检查。

## 预警联动流程
1. 视觉质检智能体在连续缺陷出现时自动推送预警并关联疑似工艺原因；
2. 班组长 10 分钟内确认是否为检测误报（抽查实物）；
3. 非误报则按缺陷类别打开对应工艺文件执行排查表；
4. 排查结果回填系统，形成闭环记录。

## 常用排查顺序
先看周期性（换辊/辊道）→ 再看温度曲线（加热/冷却）→ 再看介质（除鳞水/乳化液/保护渣）→ 最后查成分（残余元素/夹杂物）。

## 检测误报常见来源
- 图像光照突变、水雾、油渍反光；
- 标签与实际缺陷类别标注偏差；
- 模型置信度低于 0.5 时的低可信输出（建议按机台加密复检）。
