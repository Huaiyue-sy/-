# 工艺文件：斑块（patches）【模拟文件，供智能体 RAG 演示】

## 缺陷定义
钢板表面边界不清的块状/片状区域，与基体存在色差或轮廓差，尺寸从数毫米到数十毫米。

## 常见工艺原因
1. **轧辊磨损不均**：精轧 F4 以后辊面局部磨损，带钢出现周期性斑块，周期=轧辊周长。
2. **局部过热/温度不均**：板坯头尾或边部温度偏差超过 30 ℃，压下后表面变形不一致。
3. **异物压入后脱落**：局部压入物脱落后留下浅坑与色差。
4. **除鳞不均**：水幕覆盖不连续造成带状/块状氧化残留。

## 关联工序
粗轧 → 精轧 → 卷取。

## 处置建议
- 测量斑块间距：等间距优先换辊并核算辊周长对应关系；
- 核对板坯出炉横向温差记录；
- 检查除鳞水幕覆盖完整性。

## 预防措施
- 建立轧辊磨损数字档案，磨损量到达阈值自动提醒换辊；
- 加热炉横向温度均衡性纳入班检；
- 除鳞水幕做水压/流量双表校验。
