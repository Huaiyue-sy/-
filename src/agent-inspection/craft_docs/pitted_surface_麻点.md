# 工艺文件：麻点（pitted surface）【模拟文件，供智能体 RAG 演示】

## 缺陷定义
钢板表面密集成片的细小点状缺陷，直径多小于 1 mm，分布区域较大，常伴表面粗糙。

## 常见工艺原因
1. **轧辊表面疲劳剥落**：精轧前段辊（F1–F3）轧制公里数超限，辊面出现微剥落并反向复印到带钢表面。
2. **高温氧化与冷却不均**：出钢温度过高且层流冷却边部水量不足，边部麻点加剧。
3. **轧辊磨损不均**：辊面硬度差异大（HSD 差 > 5）时低硬度区先磨损形成麻面。
4. **乳化液清洁度差**：热轧润滑乳液铁粉含量超标，辊面结膜异常。

## 关联工序
精轧机架 → 层流冷却 → 卷取。

## 处置建议
- 核对各机架轧辊上线公里数，超限机架优先换辊；
- 检查乳化液浓度（2.0%–3.5%）与铁粉含量；
- 麻点集中在上表面时优先排查上辊系。

## 预防措施
- 按轧制计划严格执行换辊周期；
- 每次换辊记录辊面硬度；
- 乳化液系统按周期反冲洗。
