# 工艺文件：划伤（scratches）【模拟文件，供智能体 RAG 演示】

## 缺陷定义
带钢表面沿轧制方向分布的直线状或弧线状沟痕，长短不一，手感可辨，多见于下表面。

## 常见工艺原因
1. **轧制速度与张力失配**：精轧速度超过工艺卡上限 5% 且张力波动大时，带钢与导卫装置相对滑动加剧。
2. **导卫/活辊表面有异物堆积**：氧化铁皮、碎屑在辊面结瘤，划伤呈周期性分布。
3. **卷取机助卷辊状态不良**：助卷辊轴承磨损后辊面跳动，产生间隔规则的划伤。
4. **输送辊道个别辊子不转**：停转辊与带钢干摩擦，划伤位置固定。

## 关联工序
精轧 → 层流冷却段 → 卷取机 → 输出辊道。

## 处置建议
- 检查划伤位置是否周期性出现：周期性优先排查停转辊/助卷辊；
- 清理导卫装置与活辊表面积屑；
- 按辊号对照划伤间距确定责任辊并更换。

## 预防措施
- 每班巡检辊道转动状态，安装辊面测温；
- 控制精轧加速度在工艺窗口内；
- 建立助卷辊轴承振动监测台账。
