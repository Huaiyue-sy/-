# 实训报告

结果考核 40%，要求覆盖**软件需求分析 → 编码实现 → 系统测试**整个开发周期。靠平时积累，不要最后一晚拼。

建议章节：

1. 实训概述 —— 题目、分组分工、三周进度对照 `docs/` 里的规划图
2. 需求分析 —— 业务背景（轴承故障诊断 / 表面瑕疵质检）、数据来源与规模、功能与非功能需求
3. 系统设计 —— 总体架构图、模块划分、数据流、模型选型理由
4. 编码实现 —— 环境与依赖、关键代码片段、特征工程与模型训练过程、参数设置
5. 系统测试 —— 测试方案、指标（准确率/召回/F1/混淆矩阵）、对比实验（CNN vs LSTM vs 随机森林、ResNet vs EfficientNet vs YOLO）、结果分析
6. 智能体应用 —— 工具调用、记忆、推理、决策四模块实现方式与演示截图
7. 问题与改进 —— 从 `实训手册/` 的每日记录里提炼，这是最能体现工作量的部分
8. 总结与心得

写作要求：图表有编号和标题，代码只贴关键片段并注明文件路径，实验结果一律用表格呈现。
